# SQL Layer

This folder contains SQL implementations used to build analytical datasets and reporting tables for business decision-making.
The SQL code focuses on data modeling, metric definition, and transformation of transactional data into BI-ready structures. All queries are production-oriented and adapted for public portfolio use without exposing sensitive information.
Key metrics are defined explicitly and calculated using consistent, reproducible logic. Special attention is paid to customer lifecycle modeling, attribution, and period-based aggregation to ensure analytical correctness.
The SQL layer serves as a single source of truth for downstream dashboards and reports, minimizing ambiguity and simplifying BI consumption.
Queries are written with readability and auditability in mind, with comments explaining non-obvious logic and business assumptions.
